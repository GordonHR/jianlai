# 剑来卡牌对战原型 · 本轮改动概览

## 对战界面 / 特效 / 全角色技能（2026-08-29 第三轮）

### 一、单屏九宫格布局（参考三国杀）
原版是「顶栏 → 敌区 → 牌堆 → 自己大卡(246px) → 手牌 → 技能 → 战报」竖排堆叠，必须滚动才能出牌。改为锁 `100vh` 的 grid：

```
[顶栏：轮次·阶段步进器·换景/节奏/音效/结束回合]
[敌区(横排小卡)      |  战报抽屉
 牌库 | 中央出牌展示区 | 弃牌        ]
[我的武将(竖版小卡) | 扇形手牌 | 技能区]
```
- 中央新增**出牌展示区**：最近打出的一张牌放大摆中间，配招式名与出招者（`.bf-stage` / `.stg-card`）。
- 手牌改**扇形叠放**（负 margin + 逐张旋转，张数越多单张旋转越小防裁切），hover 抬起并让位。
- 我方武将由 158×246 横版大卡改为 184px 竖版小卡，与手牌区等高。
- 战报改为右侧独立滚动抽屉（保留 40 条，自动滚到底）。
- 技能区移到右下竖排，按钮带 `title` 说明，底部加「退出战局」。
- 手机 `mobile/index.html`：竖屏三行（战场 / 战报 92px / 我方），手牌仍横向滚动。

### 二、卡牌特效：一牌一景
新增 `fxCardPlay(p, card)` 派发器，六类牌各走各的特效：

| 牌 | 特效 |
|---|---|

另新增技能特效 12 种：`sword / shield / lotus / flame / thunder / mist / rune / forge / star / blood / scroll / aura`。新增 `SFX.wine()`（饮酒）与 `SFX.rune()`。
**顺手修了手机版的既有 bug**：`mobile/index.html` 的 body 里根本没有 `#flash` / `#combo` 两个容器，闪屏与连击特效在手机上一直不显示；已连同新的 `#drunkfx` 一起补上。

### 三、全角色技能引擎（109 人 / 195 条）
之前 109 人里只有 5 个旗舰（陈清都/道祖/周密/阿良/齐静春）+ 米裕/宁姚/白也等零星几个真正进了引擎，其余的 `skills` 只是 CHARS 里的描述文本。现在补成声明式技能表：

```js
SKILLS[角色key] = [ {n 名, k 类型, v 数值, c 条件, o 限定, a 主动技, q 喊话, qo 原著原话, f 特效} ]
```
- **27 种技能类型**：atk / atkLimit / hand / draw / judge / range / nodist / nododge / reduce / reflect / immune / taunt / regen / hitdraw / hitextra / deathsave / deathally / deathfac / killdraw / startcard / startequip / equipUp / act / useAs / dodgeAs / auraAtk / flavor。
- **接线点**：出剑次数、手牌上限、摸牌、剑气伤害（含明细归属）、守心判定、掉血减伤/反弹/濒死自救、回合末回气、命中后摸牌与再出一剑、阵亡与击杀触发、开局发牌与专属飞剑、锦囊免疫、嘲讽选敌、论道先讲道理（判定点数低者先弃一牌）、牌转化（守心当剑气 / 锦囊当守心）。
- **距离**做成真实概念：`distOf()` 座次距离，`range` 扩展，`nodist` 无限；未达标即为「远」，喂给 `c:'far'` 类技能（如左右【出城】）。
- AI 的 `aiTrySkills` 改为数据驱动，会按表使用所有主动技（此前只会用 5 个旗舰的）。
- 战报归属：剑气命中会打印「剑气 3 点：本命飞剑 +1、镇蛮 +1、齐心 +1」。
- 人物卡与武将卡的技能名带 `title`，悬停显示效果说明 + 台词。原著原话用 `qo:1` 标注（如阿良「我叫阿良，善良的良」、齐静春「遇事不决，可问春风」、至圣「有教无类」、道祖「道法自然」、老子的「无为而无不为」「三生万物」、诗经「高山仰止，景行行止」、庄子「心斋坐忘」）；无可靠原话的角色写的是贴合人物的招式喊话，未冒充原文。

### 四、平衡：对照采样（项目纪律）
- **首次接入后守城胜率崩了：98% → 7%**。消融实验逐类停技能，定位到 `deathsave`（濒死自救）：守城每波刷新新的敌人，等于每波白送一条命，波次永远清不掉。
- **修正**：濒死自救需弃 2 张牌，无牌则救不得。
- 最终对照（同采样器 N=40）：守城 98% → 93%，讨伐 100% → 100%，混战 100% → 100%，回到噪声范围内。

## 「画意」图案特效 + 全局手感升级（2026-08-30 第四轮）

回应用户核心诉求：**特效要能做出「图案 / 形象」**，例如「喝酒就是一个人拿出酒壶仰头畅饮」。
此前全部特效均为 CSS 几何粒子（光点 / 线条 / 涟漪），没有任何「形象」。
方案：**纯内联 SVG 手绘水墨剪影**，不依赖位图素材与外部库，天然贴合《剑来》水墨气质。

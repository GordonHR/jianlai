## 零、一句话结论

**三个叙事模块里，山水祠最贴原著（几乎可以从原著里一一坐实），书简湖次之，落魄山体量最大但偏差也最多。**
"剧情丰满"这件事，目前是**横向铺得开、纵向不够深**——事件够多、结局够多，但选择与选择之间没有因果链，玩完一局记住的是数值曲线，不是"我做了什么导致了什么"。
最该改的不是加内容，而是修三处**设定硬伤**和一处**人称破裂**，再补上落魄山真正缺的那批人（供奉与魏檗）。

## 二、逐模块诊断（只列有据可查的问题）

### 2.1 山水祠 —— 保持，只补一处说明

先说对的（这一模块可以当标杆）：

| 游戏设定 | 原著依据 | 判定 |
|---|---|---|
| 辖地＝棋墩山土地 / 埋河水神 | 魏檗由北岳正神被贬为**棋墩山土地公**；陈平安出藕花福地后结识**埋河水神**，传授其顺序之学 | ✅ 双源头，不是编的 |
| 品阶：土地公 → 山神 → 山君 → 北岳正神 | 魏檗正是"被贬土地 → 山神 → 北岳正神"，神号夜游 | ✅ 完全对应 |
| "脱根"：位阶越高，脚下土越薄 | 山水神祇玉璞境已是极致，再进需渡**神道天劫**，且极易**脱离山水根基、失去神职依托** | ✅ 机制即设定 |
| 结局「沉江」：金身打碎抛进江里 | 魏檗金身被神水国遗民后人打碎沉江 | ✅ 直接坐实 |
| 事件「老狐求名」ban 掉"许它山神之位" | 项目铁律"狐精不可为山神" | ✅ 铁律守住了 |

**唯一建议（纯文案，零数值）**：玩家顶的是"棋墩山土地"这个位子，而这是魏檗的位子。
开局加一句**交代身世**即可——例如"你是接任这座小庙的第三位土地，前一位姓魏，走得很不体面"。一句话把玩家从"扮演魏檗"的违和里摘出来，又保留原著地名。**不要**改成魏檗视角，那会与已知结局冲突。

### 2.2 书简湖问心局 —— 骨架对，一个数字待考

对的部分：设局人崔瀺 ✅、顾璨杀孽 ✅、碎文胆代赎 ✅、账房先生 ✅、为湖上立规矩 ✅。
19 个结局按"碎胆 / 血洗 / 公断 / 立碑"四条路线收束，逻辑自洽，且每条都给得出"代价"，符合"好选项必有代价"。

**待考**：文案反复出现"**三十七户**"。原著我能核到的是"顾璨利用小泥鳅在书简湖大开杀戒""召出无数冤魂"，**没有核到具体户数**。
处理建议：要么在结局文案里去掉确数（"那些人家"），要么标注为游戏原创设定。按项目"未载标推定"的铁律，现在这样写是有风险的。

### 2.3 落魄山 —— 体量最大，五处问题

#### 问题 1（最重）：终局节点"第五年飞升之争"原著无据

多方检索**未找到**原著有"飞升之争"这一设定。原著落魄山线的终局是：
**共斩蛮荒 → 落魄山建宗大典 → 问剑正阳山 → 遍访山水神灵、以文庙功德修复桐叶洲 → 建下宗青萍剑宗**。

"争一个飞升名额"这个目标，气质上跟原著 finale 是拧的——原著陈平安从来不是去"争"什么，他是在"还"和"守"。
**建议改法（三选一，成本都低）**：

| 方案 | 终局节点 | 说明 |
|---|---|---|
| A（推荐） | **落魄山建宗大典** | 最长脸也最原著。各方剑仙来贺，贺礼与到场名单由你前五幕的人情决定 |
| B | **问剑正阳山** | 张力最强，与"讲道理"主线呼应，且能直接接一条新模式（见 §五） |
| C | 保留飞升之争，但改名为"**立世之争**" | 最小改动，去掉"飞升"这个原著敏感词 |

#### 问题 2：弟子名单与"八弟子"对不上，且有一个身份错误

原著落魄山八弟子：**崔东山、裴钱、曹晴朗、赵树下、郭竹酒、宁吉、邓剑枰、袁黄**（收徒重品性轻天赋）。

现在 `SECT_DISCIPLES` 是：裴钱、曹晴朗、崔东山、陈暖树、周米粒、李宝瓶、顾粲、裴杯。

- ❌ **李宝瓶不是陈平安的弟子** —— 她是齐静春的弟子，称陈平安"小师叔"。列进门下是硬伤。
- ❌ **顾粲不是弟子** —— 是"异父异母的亲弟弟"，书简湖那段正是因为他不是门内人才难办。
- ⚠️ **裴杯存疑** —— 各来源均未检到；游戏内 `CHAR_PATH` 已标 `src:'推定'`（"裴钱授业之一，止境"），但放进"弟子"序列会误导。原著与"裴"相关的知名角色是**裴旻**（浩然三绝之一），需确认是否讹变。
- ⚠️ **陈暖树（小管家）、周米粒（右护法）** 是门中人但不是弟子，混在弟子池里稀释了"收徒"这件事的分量。
- ➕ **缺 5 人**：赵树下（武道关门弟子，两百万次基础拳法）、郭竹酒（金丹剑修）、宁吉（天生道胎）、邓剑枰（剑道心结）、袁黄（打破"不再收徒"规矩者）。这五人每个人都有现成的"入门理由"，是最省事的扩容素材。

**建议**：拆成两层——`弟子`（按原著八人补齐）+ `门中`（暖树、灵均、周米粒、朱敛、韦文龙、长命），李宝瓶与顾粲改挂"同道/故旧"，不走弟子通道。

#### 问题 3：落魄山最值钱的东西没做 —— 供奉、客卿、魏檗与夜游宴

落魄山在原著里的味道是"**群魔乱舞**"：首席供奉姜尚真、小陌、谢狗、天然、种秋、米裕、魏晋、于樾、李柳……各路豪杰来投。
游戏里这些人一个都没有，山上只有 8 个弟子——**少了整座山最热闹的那一半**。

尤其该补的是 **魏檗 + 夜游宴**：

> 落魄山缺钱就办夜游宴。北岳地界大小山头、山水神灵叫苦不迭——"大公鸡上披云山都得留下两个蛋才能走"。
> 后来他在一座储君之山续办夜游宴，竟为落魄山**攒下一半家底**。

这是**天然的"好选项必有代价"机制**：办宴 → 得神仙钱与机缘，但欠下人情（日后必被讨要）、清誉下降（民间戏称"两袖清风披云山"）。
成本极低（一个行动 + 一组人情事件），收益极高（把"缺钱"这个最枯燥的经营痛点变成有原著称的社交博弈）。**强烈建议做。**

#### 问题 4：人称破裂（POV）

模块注释写"玩家扮演山主（**陈平安一脉**）"，但结局文案里出现：

> "落魄山从此不是地图上的一个点，而是一句「**陈平安的**山头」。"
> "你借十四境之力，随宁姚等人直入蛮荒托月山……"（`tuoyue_end`）

第一句把玩家和陈平安切成两个人，第二句又把陈平安的经历直接安在玩家身上。**同一模块里两种身份，玩家会卡。**

**建议二选一、全模块统一**：
- **甲案**：玩家＝陈平安本人。所有结局改用第一人称，"陈平安的山头"改为"你的山头"，`tuoyue_end` 保留。
- **乙案（更稳）**：玩家＝落魄山山主，陈平安是"先生/前山主"。那 `tuoyue_end`、`zhixing_end` 这类直接搬陈平安经历的结局必须改写成"你替他守住了这一步"。

我倾向**甲案**：改动面小（只改文案不改逻辑），且玩家进这个模式本来就是想当陈平安。

#### 问题 5：六个幕名很好，但与事件池没有因果

`SECT_ACTS` 用真实册名分幕（骊珠洞天 / 负笈大隋 / 藕花问心 / 剑气长城 / 落魄开宗 / 天下风波），这个设计是**全项目最好的点子之一**，别动。
问题是：93 个事件是**随机抽取**的，幕只是"翻书进度条"，不决定会发生什么。第 1 幕可能抽到剑气长城的事，第 4 幕可能抽到求雨。

### 2.4 卡牌对战 —— 改编合理，一个词要小心

109 角色 / 195 技能 / 四模式，工程完成度很高，不重复评。只说原著层面：

- ✅ "本命飞剑""问剑""讲道理""锦囊＝读书/炼器"这套映射是成立的。
- ⚠️ **"问剑（酒）"**：项目已在 08-31 核过，原著"问剑＝多递出一剑"，**与酒无关**。酒来自阿良"饮者"与第 581 章酒墙，是另一条线。现在把两者焊在一起（问剑牌＝酒牌、饮酒特效），属于三国杀"酒"的映射。
  **建议**：牌名改为「**饮者**」或「**且饮此杯**」，特效（仰头举壶）原样保留，问剑回归"多递出一剑"的语义。改的是显示名，不动 k/v，零平衡影响——正是项目 MEMORY 里说的"修正设定错误最佳改法"。

## 三、"剧情更丰满"的真正瓶颈（不是加事件）

现在的问题不是内容不够，是**三件结构性缺失**：

### 1. 选择不产生后果，只产生分数

落魄山现在是：`flag/道契打分 → sectRouteEnding() 选结局`。
这是"评分制"，不是"叙事制"。玩家做完 54 个抉择点，记住的是"我道心 46、名望 30"，不是"我在第三幕没救那个人，所以第五幕他没来"。

**最小改法（不动数值）**：给关键事件挂 `mark`（标记），后续事件按 mark 换文案、换选项。
举例：`aliang_meet` 里若你回了阿良那句"我叫阿良，善良的良"，记 `mark:aliang_friend`；第五幕建宗时若 mark 存在，阿良到场并多一条贺礼分支。**加 3–5 条这样的回响，丰满度的提升远大于加 20 个新事件。**

### 2. 没有人，只有数值

落魄山的灵魂是人，但游戏里裴钱、曹晴朗、崔东山都只是 `base/loyal/dao` 三个数。
建议给核心 5–6 人各加一条**"心事"线**：每人 3 个节点，靠特定选择推进（裴钱需要"被当众认可是弟子"、曹晴朗需要"你愿意立规矩"、崔东山需要"你信他一次"）。这条线不通，该角色就不会在终局出现。
这既原著（陈平安收徒本就是"教化"而非"招募"），也直接治好了问题 1。

### 3. 没有"山主不在山"的张力

原著最有戏剧性的设定是：**陈平安几乎一直在路上**。护送李宝瓶、南下送剑、藕花福地、北俱芦洲、剑气长城——山上常年是"一群不顶事的老人和孩子"，是魏檗在当家。
游戏里山主永远坐镇，反而没了这层。

**建议**：第 2/4/6 幕强制若干旬"**远行**"，此期间只能远程决策（信息不全、选项变少、代价更高），山上由大管家/魏檗托管。这既补了张力，也天然解释了"为什么经营会有意外"。

## 五、新模式建议（4 个，附体量与 2MB 评估）

排序＝原著张力 × 实现性价比。全部可复用现有"旬 + 资源 + 事件卡"骨架，不必新建引擎。

### ① 隐官 · 避暑行宫（最推荐）

**原著**：陈平安临危受命任新隐官，"以避暑行宫为官署，调度剑气长城所有剑仙"，硬生生把大战拖了三年，救下两万多人。

**玩法**：一张防线图 + 每旬有限的人手 + 按波次来的敌情。把剑修（带能力标签：守/攻/速/镇）派到各战场点。**总有点守不住**——这正是原著的悲壮，也是它比"守城模式"高级的地方：你不是在赢，你是在决定**哪里先塌、塌多久**。

**为什么值**：原著里戏剧张力最足的一段，且天然是"旬"节奏，与落魄山互为镜像（那边山主在守家，这边隐官在守城）。
**体量**：≈ 半个山水祠。纯数据 + 复用渲染，**双端增量可控**。

### ② 问剑正阳山（远征爬塔）

**原著**：陈平安十境归真后"携落魄山一众问剑正阳山"，与刘羡阳一路打到山顶，报当年搬山猿之仇。

**玩法**：一山一关，每关一位守山人（直接复用 `CHARS` 现成数据）。战损继承、中途可"退"——但退了就得认下"正阳山还在那儿"。
**体量**：小。可与卡牌引擎复用，也能做成落魄山终局的一个分支（呼应 §2.3 问题 1 的方案 B）。

### ③ 夜游宴（挂进落魄山，不独立成模式）

见 §2.3 问题 3。它是**子系统**不是新模式，但优先级应该最高——因为它治的是落魄山当下最真实的痛点（缺钱没味道）。

### ④ 藕花福地 · 带谁走（道德抉择小局）

**原著**：陈平安误入藕花福地，成为福地十人之首，**有权带走五人**。

**玩法**：10 个人，5 个名额。每人有来路、有理由、有你不带走他会发生什么。
**为什么值**：极小的体量，极大的重量——而且它天然能喂给落魄山（带走的人成为你的弟子/门中），把两个模块缝起来。
**体量**：最小。

## 卡牌 SVG 插画：四版迭代（前三版否决）
- v1 纯线条图标（否决，像草稿图标、无牌面感）→ v2 水墨晕染（否决，脏灰块/黑棍/红十字；**手写 SVG 模拟水墨是死路**）→ v3 白描线稿（否决）→ v4 粗块面高对比（本版）。
- **v3 被否根因（关键）**：不是方向错，是**执行尺度错**——stroke-width 仅 0.5–1.6、设色 opacity 仅 0.08–0.12、细节碎（6 道缠绳/多层结构）。卡牌在手机仅约 **170rpx 宽（物理 ~85px）**，viewBox 100×140 缩到该尺寸后：细线 <1 物理像素直接消失、极淡设色看不见、碎细节压成噪点 → 视觉"空、糊、廉价"。
- **结论：白描线稿在移动端小尺寸不成立。** 小尺寸只能靠"形状块面 + 强明暗对比"识别，不是细节线。
- **v4 新标准（小尺寸可读性五硬指标）**：①粗轮廓 stroke-width **2.5–3.5**（禁 <2）②高对比：主体**深色实块 fill**（`#241c14` 墨黑/`#2a3b3f` 深青/`#4a3520` 深赭/`#6e4f23` 古铜/`#7d5a2a` 浅赭），**禁 opacity ≤0.15 极淡设色** ③大块面靠形状识别，线条仅点缀 ④砍细节：每主体仅留 1–2 个识别特征（删多道缠绳/层层内部结构）⑤主体占卡面 70–80%（非 55–65%）。
- 保留：宣纸底 `#f6eed8→#ece1c2`、双铜框（外3/内1.2）、右下朱印、金色 `#c9a24b` 点缀关键特征。
- 体积：attack 1812 / dodge 1418 / heal 1619 / wine 1716 / trick 1800 / equip 1955 B ≈ 共 10.3KB。worker 用 headless Chrome 实际渲染到 85px 验证可读性（比读代码可信）。
- **跨会话铁律**：小程序/移动端 SVG 图标与卡牌，**先按"缩到 85px 还能不能一眼认出"做设计**，再谈风格。细线稿+淡设色在小尺寸必糊。
- 过程教训：给美术 handoff 要附**反向约束**（"不要XX"）并先出 1 张样例验收；同一 worker 连续两次翻车后应换 fresh worker 换视角。

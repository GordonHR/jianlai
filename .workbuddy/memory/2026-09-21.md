## PC 端舆图满屏（去四周留边），与小程序 canvas 观感一致

**任务**：用户截图反馈 `浩然天下地图.html` 四周有黑边（1080×530 视口下左右各约 154px），要求"跟小程序一样不该有黑边，因为地图不会这样"。

**根因**：`#map` 写死 `viewBox="0 0 1600 1100"` + `preserveAspectRatio="xMidYMid meet"`。
`getBoundingClientRect()` 返回整屏 CSS 盒，内容按 viewBox 等比居中 → 视口宽高比不同即留边，
露出 `.mapstage{background:#2a2419}`（即用户看到的黑边）。骊珠层 `#lizhuMap`（1400×1000 + meet）同病，全屏时露 `.lizhu-body` 纸色边。

**改动（全部在 `浩然天下地图.html`）**
1. 新增 `fitBox(el,bw,bh)` / `fitWorldVB()` / `fitLizhuVB()` / `fitStage()` + `window resize` 监听：
   viewBox 用**元素自身** gBCR 算 `k=min(W/bw,H/bh)`，等比向外撑开并**居中**（内容中心仍 800,550）。
   → 内容缩放仍 == meet 缩放（**只补边、不裁内容**，图例/指北针/南婆娑洲都在），观感与原先一致。
   **不用 `slice`**：实测 1080×530 会裁掉南北各 106px，图例（y980~1072）直接不见。
2. 满铺续接层：`bleedBase(painted)` + `BLEED_WAVE`（大矩形 `x=-4000 y=-4000 w=9600 h=9100`），
   插在原背景矩形之前（同层序）。矢量画风 `fill="var(--ocean1)"`（`#ocean` 径向外圈即此色 → 边界同色无缝）
   + `url(#sea)` 浪纹（`patternUnits=userSpaceOnUse` → 跨边界必然对齐）；
   写实绘卷改取底图边色：PIL 实测 `haoran-painted.png`(2048×1408) 四边均值 左#8ca1a8/右#94a6ad/上#b8c6cc/下#9cacb2，取 **#9dafb6**。
3. 坐标换算写死 `1600/1100` → `vbX/vbY/vbW/vbH`：`clientToSvg`、鼠标拖拽增量、触屏拖拽、`touchMid`。
   **顺带修掉一个既有 bug**：letterbox 下拖拽速度与缩放锚点本就和光标不同步（映射系数差 1080/771）。
4. 骊珠层：满铺纸色矩形 `fill="#d2bf94"` 放在 `#lizhuViewport` **之外**（不随缩放平移）；
   `.lizhu-body` 背景 `#cdbb93`→`#d2bf94`（与 `#parch` 最外 stop 同色）；
   `enterLizhu` 先 `display='block'` 再 `fitLizhuVB()`，`exitLizhu` 恢复容器显示后 `fitStage()`（隐藏元素 gBCR=0，顺序错了会跳过）。
5. 新增 `.ocean-bleed{pointer-events:none}`。

**验证**

## 续：消除「明显框 / 矩形边界」（黑边修复后的二次反馈）

**反馈**：用户截图（jinbi 金碧画风，1887×959，约 59% 缩放）「没有黑边但是还是很明显的框」。即黑边没了，但画面仍有一圈明显矩形框。

**根因（量化复现）**
- 场景里原来放了一块 **不透明的 1600×1100 海色矩形**（旧 `bleedBase`+ocean rect），其边缘与续接色存在约 **40/255 的色阶跳变** → 用户看到的「框」。
- 缩放越小，该不透明矩形缩得越靠内、越可见（RENDER-jinbi-z1 在 246/1641 出现 SEAM 阶跃 40；用户截图约 59% 缩放时框在 501/1326）。
- 同时 `#oceanbg` 满铺底当时只写了 `0,0,1600,1100` 的矩形，宽屏下 viewBox 是 offset（如 `-320.8 0 2241.5 1100`），**盖不住负区/超界区** → 会重新露出 `.mapstage` 暗底（黑边复发）。

**改动（同文件 `浩然天下地图.html`）**
1. `ocean` / `parch` 径向渐变改 `gradientUnits="userSpaceOnUse"`，锚在**图幅中心**（ocean: 800,506 r=1120；parch: 672,400 r=1120）→ 越出半径即平接到 `--ocean1`/`#d2bf94`，**永不出现「渐变没走完就被截断」的硬边**。
2. `#oceanbg`（屏幕固定层，在 `#scene` 之外、不随缩放平移）的 rect 从 1600×1100 改为 **巨型 `-4000,-4000,9600,9100`** → 任何窗口比例/缩放都严丝合缝盖满，地图缩小到底也不露边。
3. 场景内 `WAVE_RECT` 改为 **纯透明浪纹 `url(#sea)`**（只画线、无底色）→ 海色完全由背后 `#oceanbg` 提供，**场景内不再有任何不透明矩形去形成框**。
4. 修正层级顺序：原 `#ui-fixed`（印章/指北针/图例）在 `#scene` 之前，会被场景不透明海面盖住；改为 `#oceanbg → #scene → #ui-fixed`，UI 正确叠加在地图上。
5. huijuan 写实绘卷：`#oceanBgRect` CSS 填 `#9dafb6`（雾色平接底图边），底图四边/四角镜像续接。

**验证（headless 真渲染 + 像素门禁）**
- 渲染：chrome-headless-shell 真渲染 `?style=jinbi&zoom=1.0` / `?style=jinbi&zoom=0.6`(≈用户复现 59%) / `?style=huijuan` / `?style=shuimo`，各 1887×959。

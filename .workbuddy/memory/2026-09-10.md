## 行迹录境界图标撑爆（用户："行迹录样式彻底乱的"）
- **症状**：武夫·泥胚 的"当前境界"图标撑成 280px 巨圆，把"泥胚"二字挤成只剩一半；步梯那排的境界小图标也有同样隐患。
- **根因**：
  - `assets/realm/realm-icons.js` 的 `_rf()` 产出 `<svg class="realm-ic" viewBox="0 0 64 64">`，对应 CSS（profile.js L417）`.realm-ic { width:100%; height:100% }`。
  - profile.js L631「当前境界」处直接把 svg 放进 `<div class="pf-realm-now">`，**没有外层 `.pf-realm-ic` 58px 包装盒** → svg 的 `width:100%` 找到的容器是没有固定尺寸的 flex 容器，按内容扩张到 280px。
  - 同理 profile.js L533 步梯 `<span class="pf-step">` 里也缺 18px 容器；CSS 里写了 `.pf-step .ric { 18px }`，但 svg 的 class 是 `realm-ic` 不是 `ric`——**类名错配导致规则根本匹配不上**。
- **修法（两处协同）**：
  1. `assets/realm/realm-icons.js` 第 17 行：`<svg class="realm-ic" viewBox="...">` → `<svg class="ric" viewBox="...">`。类名改为 `ric` 命中 profile.js 已有的 `.pf-step .ric`/`.badge-realm .ric`/`.cr .ric` 三条规则；**绝不能加 inline `width:100%`**，否则 inline 样式压过外层 CSS、步梯那排仍会撑爆。
  2. `profile.js` L631：当前境界 svg 外加 `<span class="pf-realm-ic">` 58px 包装盒；同步在 CSS 写 `.pf-realm-ic svg, .pf-realm-ic .ric { width:100%; height:100% }` 让包装盒内的 svg 充满（这是唯一需要 fill-100% 的场景）。

### 第二轮："还是乱的呀，图标贼大"（步梯撑爆）
- **新症状**：当前境界那张已修好；步梯那排（泥胚/木胎/水银…）仍然每个 ~200px 巨圆。
- **根因**：第一轮在 realm-icons.js 给 svg 加了 `style="width:100%;height:100%;display:block"`——inline 样式优先级 1000+，**压过**外层 CSS `.pf-step .ric { 18px }`，svg 按 100% 撑爆。当前境界那张因为包了 `.pf-realm-ic` 58px 包装盒没暴露问题，步梯那排没有包装盒就露馅了。
- **正解**：SVG 不要 inline 样式，**全部走 CSS 路由**——`.pf-step .ric { 18px }` / `.badge-realm .ric { 15px }` / `.cr .ric { 14px }` 各自命中；只有 58px 包装盒场景需要额外 `.pf-realm-ic svg { width:100%; height:100% }`。
- **复盘（写入 MEMORY §7）**：realm-icons.js 的 svg **禁止 inline 尺寸/100% 样式**，只保留 `class="ric"` + `viewBox`；外层包装盒需要时另起 CSS 子选择器。
- **验证**：`node --check` 双文件全过；svg 起始 `<svg class="ric" viewBox=...>` 无 inline style；profile.js 多了 `.pf-realm-ic svg, .pf-realm-ic .ric { width:100%; height:100% }`。

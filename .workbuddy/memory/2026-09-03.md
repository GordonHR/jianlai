- 用户多轮反馈收敛路径：居中 ✓ → 字太小 → 顶部对齐 + 首列空两字 → 不要按字数区分字号/不要固定折列 → **"我不是要单列，到底了就要折列"**。
- **最终定案（两端 1:1）**：牌文不再做 JS 分列、不再按字数动态调字号。
  - **统一字号**：PC `30px`、小程序 `44rpx`（所有牌一致，避免短牌空旷/长牌拥挤）。
  - **写满一列折左一列**：CSS `writing-mode:vertical-rl` + `column-count:12`（上限，实际按内容）+ `column-fill:auto` + `max-height:100%` + `overflow:hidden`。浏览器按弹框高把每列撑满，内容满则从左往右/右往左折到下一列；短牌自然 1~2 列、长牌多列，视觉是连贯书写。**之前用 `column-width:5em` 在竖排下未触发折列（只单列截断），改 `column-count` 后正确**。
  - **首列空两字**：`wspSplit(t)` 返回 `'　　' + t`（两个全角空格起首留白），不再切分多段。
  - **顶部对齐**：`.wsp-dt-words { align-items:flex-start }` + `.wsp-dt-panel { justify-content:flex-start }`，文字从弹框上缘写起（保留 padding 不与边缘贴死）。
  - **card 米色兜底** + 模糊立绘做底保留（不溢出、字清晰）。
- **渲染层简化**：`wspDetail` 删 `colHtml/sp.fs` 内联字号，单 `.wsp-dt-txt` 包 `wspSplit` 返回的整段；小程序 WXML 同样去掉 `font-size` 内联、保留 `wx:for` 渲染 `detail.cols`（单元素）。
- **门禁**：T23 改为断言 `font-size:30px` + `column-count:12` + `column-fill:auto` + `align-items:flex-start` + 首列两全角空格 + `linear-gradient(168deg,#ecdcbe` 米色兜底；`_sc_wxwsp.cjs` 修脚本自身语法错（单引号字符串跨行 → 改 `'\n;globalThis.WSP_CARDS=WSP_CARDS;'` 单行）。
- **验证**：PC `_sc_smoke.cjs` **23/23**、小程序 `_sc_wxwsp.cjs` **7/7**、山水祠 28/28 全绿；`wushipai.js` bump `?v=20260903j`。
- **可复用结论**：竖排长文"写满一列折下一列"必须用 `column-count` + `column-fill:auto`（而非 `column-width`），`column-width` 在 `vertical-rl` 下控制的是列水平宽而非列高，易致单列截断。

## 第 6 轮：太平无事牌 · 撤回全部竖排/分列/字号档位，回到最朴素的横排

**核心踩坑（必须立铁律）**：用户多次被我用"竖排+writing-mode:vertical-rl+column-count+column-fill+首列空两字+字号档位"这套复杂设计困住，本轮终于明确撤回："就这么难吗？""是不是你想复杂了""就是在意这个弹框里面从上往下从左往右展示文字"。我误判 6 轮才听懂。

**最终实现（两端一致）**：弹框内 `.wsp-dt-txt` 最朴素的横排——
- 删除 `writing-mode:vertical-rl; text-orientation:upright`（竖排）

- 删除 `wspSplit()` JS 函数（不再按字数切列/调字号）
- 删除首列空两字 `'　　'`（不再需要竖排起首留白）
- 统一字号：PC `font-size:22px`，小程序 `font-size:34rpx`，`line-height:1.9`，`text-align:left`
- 渲染：直接 `<div class="wsp-dt-txt">{{c.t}}</div>`，不再用 `<text wx:for="{{cols}}">`

**改动文件**：

**铁律**：

# 2026-09-05 山水祠

## 山水祠账本「选择时 − / 结算 +」bug 修复（双端）
- **根因**：旧 `scSettle()` 把账本基线 `before` 拍在「抉择之后、自然经营之前」，于是玩家本旬抉择消耗被当旬自然收入（山水供养/气数回润）盖过，账本只显示净漂移（`after − before`），消耗不可见 → 用户感知「选择时飘字 − / 结算却 +」。
- **修复点（weapp `utils/shenci.js` + PC `shenci.js` 同步）**：
  1. 状态加 `turnStart`（回合开始基线，抉择尚未落地）；`scStart` 与 `scEnterNext`/`scNextXun` 推进时间后拍。
  2. 加 `scSnap(s)` / `scLedRow(kLed,kRes,ts,before,after)` 助手。
  3. 账本每行拆三栏：**所奏** evt = before−ts（玩家抉择）、**自然** nat = after−before（被动经营）、**净** net = after−ts；校验 evt+nat===net。
  4. 渲染：`view()`/PC `renderShenci` 行内加 `.sv-net`(净大字) + `.sv-sub`(所奏/自然小字)；wxml/wxss/PC CSS 同步。
  5. `scResettle`（结算页内嵌祠务后重算）用同一种三栏算法。
- **验证**：weapp 逻辑探针确定性复现「求雨」：抉择瞬间 气数 −2（飘字），结算账本 气数=所奏 −2 / 自然 +3 / 净 +1，evt+nat===net 成立。
- 临时探针 `_sc_*.cjs`（logic/ledger/trace）已删，仅留既有 `_sc_wxwsp.cjs`（无事牌冒烟，非本次）。
- 关联：09-04 已把「祠务」小程序端改 bottom sheet + FAB（见 09-04 日记）。

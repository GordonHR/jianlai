## 修戏里戏外故事详情弹框（selTale）—— 按着跟手 + 上下滑动问题
- **用户反馈**：按住弹框拖动时元素跟手晃动；上下滑动僵硬、滚到边缘无提示。
- **截图核验**：是 `selTale`（戏里戏外 / 阿良）故事详情弹框——顶部有 cx-pchip 列出 people、阿良 beats「孟梁其人 / 十三之战 / 受托照拂 / 皆死尽」+ 末尾 note 段「阿良是《剑来》里……他活成了样（截断）」。**不是** `sel` 人物详情。
- **根因 1（跟手晃动元凶）**：`.cx-detail.cx-tale-view` 上有 `transform-style:preserve-3d` + `perspective:900rpx` —— iOS WKWebView / 小程序 WebView 下这俩会创建层叠上下文并劫持 touchmove，导致 touchmove 被错误地路由为 transform 跟手。
- **根因 2（空壳类）**：`.cx-sway` 包裹层（wxml 第 98 行 `<view class="cx-sway">`）名字暗示「随风晃动」但实际无动画，只 `position:relative;width:98%;padding:0 12rpx;margin:0 auto` —— 历史残留。
- **根因 3（边缘拦截）**：画轴木条 `.cx-detail.cx-tale-view::before/::after`（宽 14rpx，深色木纹）没设 `pointer-events:none`，会拦截两侧边缘的 touchmove，助长跟手。`.cx-axis` 本身已有 pointer-events:none，伪元素没有。
- **根因 4（滚动僵硬）**：`.cx-detail` 只有 `overflow-y:auto`，iOS 上无原生惯性滚动。
- **根因 5（无边界提示）**：滚到顶/底无视觉指示。
- **修法（5 处全部已落盘并 grep 验证）**：
  1. **去 3D 上下文**：删除 `transform-style:preserve-3d` + `perspective:900rpx`；`cxTaleUnroll` 动画只保留 opacity + filter（去掉 transform），**避免动画结束后残留 transform 层叠上下文**。
  2. **删 `.cx-sway` 包裹**（wxss 类定义 + wxml 包裹层），用注释记录删除原因。
  3. **画轴伪元素加 `pointer-events:none`**（仅 cx-tale-view 的 ::before/::after，`.cx-detail` 自身的金线伪元素原本就有）。
  4. **`.cx-detail` 加 `-webkit-overflow-scrolling:touch`**（iOS 惯性滚动）。
  5. **`.cx-detail.cx-tale-view` 加 `mask-image` 顶/底各 24~32rpx 淡出** + `padding-bottom:110rpx`（"收卷"按钮呼吸感更好）。
- **副作用排查**：人物详情弹框（`sel`）用的是 `cx-detail` 不带 `cx-tale-view`，不受影响；fade mask 只挂在 `cx-tale-view` 上，不会加给人物详情。
- **铁律沉淀**：**任何弹层若要避免 touchmove 跟手，禁止 `transform-style:preserve-3d` / `perspective` / `filter` 高开销复合**。`overflow:auto` 必须配 `-webkit-overflow-scrolling:touch` 否则 iOS 僵硬。Absolute 伪元素（伪画轴/边线/阴影环）默认会拦截触摸，凡是装饰性质一律 `pointer-events:none`。
- **验证**：WXML 标签平衡（view 开/关 70/70 = OK）；grep 确认 `cx-sway` / `preserve-3d` / `perspective:` 仅出现在注释中；预览 `_sway_fix_preview.html`。
- **坑**：bash sandbox `node` 反复 Permission denied，**改用 PowerShell 调 `D:\NodeJS\node.exe`**（或 python -c）能跑通；甚至 `[ValidateSet]` 验证了不能写 PowerShell 5.1 不支持的 `??` 语法。

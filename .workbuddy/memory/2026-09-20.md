## 人物志详情三轮：收拢残影 + 顶条消失 + 蒙版不可见 三连修
- 用户截图反馈：① 姓名/身份两行字与信息卡贴太近；② 整页立绘蒙版看不见；③ 立绘收起了但两侧还露着（没真收走）；④ 继续下滑顶部小头像条会消失。
- 根因：`.cx-hero` sticky 钉住 60vh 永不滚走→卡片两侧 16rpx 边缝露立绘；`.cx-mini` sticky 在 scroll-view 内钉不住→下滑消失；pmask .1 盖在近不透明深色卡上肉眼不可见。
- 修法：`.cx-hero` 去 sticky 改正常流（随滚动滚走、零残影）；`.cx-mini` sticky→**fixed**（常驻视口顶，z5 压过 pmask z4 保证可读）+ `.cx-char.collapsed .cx-sheet` 补 `padding-top: safe-area+160rpx` 防首行被 fixed 条盖住；`.cx-sheet` 背景 `#1a1611`→`rgba(26,22,17,.9)` + pmask `.1→.22`（立绘真正透出卡片做整页蒙版）；`.cx-hero-head` bottom 30→84rpx + `.cx-sheet` 负边距 -30→-20rpx（姓名与卡片拉开呼吸）。
- ⚠️ 通用教训：**微信 scroll-view 内 position:sticky 钉不住（往下滑就跟着滚走）**，要常驻顶部一律用 fixed + 给后续内容补 padding-top；「半透明卡片 + 低透明蒙版」要蒙版可见，卡背景必须带 alpha。

## 包袱斋双端优化（修 2 个 P0 + 堵刷钱漏洞 + 打通小程序接线）

**P0-A：小程序端包袱斋是「摆设」——买了不生效、打牌不赚钱。** 根因两层：

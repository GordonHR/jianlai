# 视频规格与调参

## 输出

- 分辨率 1920×1080，FPS 24
- 编码 libx264，`yuv420p`，`-movflags +faststart`
- 建议输出名：`剑来_角色巡礼片尾_卷轴水墨.mp4`（基线）或按日期后缀

## 时长估算

`title_sec + (N-1)*GAP_SEC + TRAVEL_SEC + 1.2 + end_sec`

例：N=111，GAP=1.9，TRAVEL=5.8，title=3.4，end=3.6 → 约 220s。

## 动画语义

- **卷轴展开**：title 前 55% `open_amount` 0→1；logo 在 local>0.42 后淡入
- **卷轴收起**：end 段 local>0.42 后 `open_amount` 1→0；文案先淡出
- **景深**：`path_blur_radius(local)`，max_r≈3.2，不完全糊
- **人名窗口**：清晰段附近显示，避免入场即出字

## 立绘更新流程

1. 新 PNG 放入 `剑来角色立绘\`（透明底）
2. 如需出场顺序，更新 `剑来人物长卷_名单.txt`
3. `preview 5` 抽查新角色裁切与姓名匹配
4. `full` 全量重渲
5. 检查名单外文件是否被文件名排序捞进（显示名逻辑会剥离 `剑来-` 前缀）

## 姓名匹配规则

- `剑来-陈平安.png` → 显示 `陈平安`
- `宁姚-少女.png` → 显示 `宁姚`
- 名单键与 stem / `剑来-{key}` / stem 包含 key 匹配，短剩余优先
